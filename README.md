## 项目简介
本项目设计并实现了一个完整的气体浓度检测系统，包括：
1. **下位机：** CH32V003微控制器 + TGS813气体传感器
2. **上位机：** PyQt6监控软件 + 实时数据可视化
3. **通信协议：** 串口通信，自定义数据格式

## 技术栈
- **嵌入式开发：** C语言、CH32V003、RISC-V架构
- **上位机开发：** Python 3.12、PyQt6、Matplotlib
- **通信协议：** 串口通信、UART
- **开发工具：** MounRiver Studio、VSCode、Git

## 运行说明
1. 确保已安装Python 3.12和PyQt6。
2. 克隆仓库到本地。
3. 在`software/Upper`目录下运行`main.py`启动监控软件。  
4. 将CH32V003微控制器连接到上位机，并确保串口通信正常。
5. 在监控软件中配置串口参数，并开始监测。
6. 监控软件将实时显示气体浓度数据。
7. 可以通过监控软件调整阈值，并设置报警功能。
8. 当气体浓度超过阈值时，监控软件将发出报警提示。

## 已知问题
  1. 上位机在运行过程中，如果串口连接断开，程序会报错，需要重新启动程序。
  2. 上位机在绘图时，如果数据量过大，可能会导致绘图卡顿。
  3. 上位机紧耦合，代码结构不够清晰，需要重构。
  4. 多线程访问缺乏同步机制，可能会导致数据不一致。
  5. 数据数组无限增长，可能导致内存溢出。
  6. 数据直接传输，没有进行数据校验，可能导致数据错误。
  7. 可变采样率尚未实现。
